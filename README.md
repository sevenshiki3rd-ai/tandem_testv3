# TANDEM v4 — UI Preview

これは **UI/UX確認用のローカルデモ** です。GitHub Pages にアップロードして利用できます。Supabaseは未接続で、他デバイスとの同期、実アカウント、実際の招待、プッシュ通知、サーバー側のアーカイブ処理は実装されていません。データはそのブラウザの localStorage に保存されます。

## 公開手順

1. ZIPを展開する。
2. GitHub の `tandem_testv3` リポジトリで、**展開したフォルダの中身** (`index.html`, `app.js`, `style.css`, `manifest.webmanifest`, `sw.js`, `icons/` など) をリポジトリのルートにアップロードする。
3. 同名ファイルの置換を確認してコミットする。古い `config.js` / `supabase.sql` が残っていてもこのUIデモは読み込みません。混乱を避けるなら削除してください。
4. GitHub Pagesの反映を待ち、ブラウザをリロード。古い表示が残る場合はサイトデータ・キャッシュを消してください。

## 操作

- ホーム: タスク名を入力してEnter → 期限を選択 → 登録。詳細設定から繰り返しタスクを追加。
- タスク: スクラッチを約91%削ると完了。右上「⋯」からタップ完了・名前変更・アーカイブ。開始ボタンで作業中に切替。
- みんな: 2列のグループカード → グループ内の活動。右上「＋」で作成・コード参加。ペアのギフトはグループ内のギフトアイコン。
- 設定: デモユーザー切替（あなた／ハル／ユウ／ミオ）。

## 制限と今後の実装

- UIプレビューとして意図的に単一ブラウザのみで動きます。Supabase接続・RLS・写真Storage・認証・招待コード発行と検証・プッシュ通知は未実装です。
- 画像はローカル保存のため多数の写真で容量制限に達する可能性があります。
- スクラッチ振動はAndroid等の対応ブラウザのみ。iPhone Safari/PWAでは利用できません。
- 週の集計・4:00の日付境界は簡易実装です。履歴の目標変更・60日アーカイブ・複数グループ承認の厳密な扱いなどは本番バックエンドで実装する必要があります。
- サンプルユーザー切替は実アカウントではありません。グループ招待コードもデモ内でのみ有効です。
- フォントは Google Fonts の M PLUS Rounded 1c と Noto Sans JP を使用。オフラインではシステムフォントにフォールバックします。
