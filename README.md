## β5（2026-10-28）入力途中のタスクが消える問題の修正

- ホームのクイック入力欄を再描画前後に復元し、セッション内で下書きを保持します。
- 入力欄を編集中・日本語変換中は12秒間隔の自動同期で画面を再描画しません。
- 同期の通信中に入力を開始した場合も、画面を再描画しません。
- タスク追加が成功したときだけクイック入力欄を空にします。
- 画面移動後にホームへ戻っても下書きを復元します。
- Supabaseの変更は不要です。

# ニンジンタスク β版 — 2026-10-28 ホーム画面改善版

## この版の更新内容（beta4）
- **iPhoneの上部アイコン**: ステータスバー・Dynamic Islandとの重なりを避けるため `env(safe-area-inset-top)` をヘッダーに適用。右上ボタンのタップ領域も44px以上に拡大。
- **今日優先の並び順**: 期限超過 → 今日が期限の一回きり・デイリー → 明日以降が期限 → 週間 → 完了済み。種類ではなく「今日やる必要があるか」で並べます。
- **📁 中長期タスクリスト**: ホーム画面の下部に期限未設定の一回きりタスクを分離表示。専用追加ボタンを設置。タスクの「⋯」→「期限を保存」で通常一覧との移動が可能。
- **タスク管理**: 「⋯」からアーカイブ（一覧から削除）できる機能を維持。データベースからの完全削除ではありません。
- **発破済み表示**: 同じタスクに自分が一度発破した場合、薄い赤色の「発破済み」に変更（再送信可能）。
- **キャッシュ更新**: `index.html` のCSS/JS参照と `sw.js` のキャッシュ名を beta4 に変更。
- **維持**: 達成コメントのフィード表示、「みんな」チュートリアル、シークレットタスク、通知、ダークモード。

ZIPを解凍し、`tandem_testv3-main` **の中身**をGitHubリポジトリ直下へ上書きアップロードしてください。GitHub Pagesの公開が完了したらアプリを再起動してください。Supabase SQLの追加実行は不要です。

# ニンジンタスク v5.1 — Push通知対応コード

v5のUIと同期機能に加えて、以下のプッシュ通知を追加しました。

- 発破されたときのプッシュ通知（赤）
- 「🥕 進んでる？」の毎時通知（日本時間8〜22時、未完了タスクがある場合）

- iPhoneホーム画面PWA・Android対応ブラウザ向けPush API / Service Worker

**注意：ZIPをGitHubにアップロードするだけではプッシュ通知は届きません。** Supabase Edge Functionと定期実行の設定が必要です。詳細は `PUSH_SETUP.md` を参照してください。

## v5の通常利用
1. Supabaseプロジェクトを作成し、匿名認証を有効化する。
2. `supabase.sql` をSQL Editorで実行する。
3. `config.js` に公開用Supabase URL、publishable key、VAPID公開鍵を設定する。
4. 静的ファイルをGitHub Pagesに配置する。
5. `PUSH_SETUP.md` に従いEdge Functionをデプロイし、毎時実行を設定する。

秘密鍵・service_role・Cronシークレットを公開リポジトリに置かないでください。
